# MiniShift

Petit projet de gestion de planning pour retravailler les fondamentaux du développement backend et frontend.

L'idée est de construire l'application progressivement, en partant d'une API simple puis en ajoutant de la logique métier autour des employés, des disponibilités et des shifts.

## Stack actuelle

- Node.js
- Express
- TypeScript
- PostgreSQL
- Docker

## Fonctionnalités actuelles

- récupérer la liste des employés
- récupérer un employé par son id
- créer un employé
- supprimer un employé
- gestion basique des erreurs HTTP

## À venir

- connexion de l'API à PostgreSQL
- ajout de Prisma
- gestion des shifts et des disponibilités
- règles métier sur les affectations
- frontend en Vue 3
- migration du frontend vers React
- ajout éventuel d'un assistant IA pour le planning

Le projet est volontairement construit étape par étape afin de retravailler les fondamentaux et de faire évoluer l'architecture au fur et à mesure.
